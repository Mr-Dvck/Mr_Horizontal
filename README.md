## Repository Structure

- `plans/` - Implementation plans and system architecture documents
- `documents/` - Analytical content explaining the flat Earth model

## Getting Started

To implement the MR. HORIZONTAL chatbot on your website:

1. Clone this repository
2. Review the implementation guide in `plans/implementation_guide.md`
3. Deploy the chatbot using the system prompt in `plans/system_prompt.md`
4. Configure access to the knowledge base using the MCP configuration in `plans/mcp_config.md`
